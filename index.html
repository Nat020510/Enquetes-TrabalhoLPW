Perguntas Frequentes

Preciso pagar para usar o Vocify?

Não! O Vocify é uma plataforma 100% gratuita desenvolvida como projeto acadêmico de Web para conectar opiniões e gerar debates saudáveis.

Como funcionam as cores e categorias das enquetes?

Ao criar uma enquete, você escolhe uma categoria (Música, Entretenimento, Escola, etc.) com uma cor de destaque personalizada, facilitando a identificação visual rápida na listagem.

Posso votar mais de uma vez na mesma enquete?

Para manter a fidelidade e confiabilidade dos resultados, cada usuário autenticado pode registrar apenas um voto por enquete.

Quem são os desenvolvedores do Vocify?
